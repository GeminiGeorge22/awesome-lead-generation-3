# Contributing to Awesome Lead Generation

Thank you for your interest in contributing!

## Guidelines

1. **Quality over quantity** - Only suggest tools you have personally used or can vouch for.
2. **Free or freemium** - Prioritize tools that offer a free tier or are open-source.
3. **One tool per PR** - Makes it easier to review and discuss.
4. **Format** - Follow the existing format: `[Tool Name](URL) - Brief description.`
5. **No duplicates** - Search the list before adding.
6. **Categories** - Place your addition in the most relevant category.
7. **Descriptions** - Keep them to 1-2 sentences. Focus on what makes the tool useful.

## How to Contribute

1. Fork this repository
2. Create a new branch: `git checkout -b add-tool-name`
3. Add your tool to the appropriate category
4. Commit your changes: `git commit -m "Add Tool Name"`
5. Push to your branch: `git push origin add-tool-name`
6. Open a Pull Request

## What We Are Looking For

- Free APIs for lead data
- Open-source CRMs and sales tools
- Useful browser extensions for prospecting
- Python/Node.js libraries for building lead gen tools
- High-quality guides and tutorials

## What We Will Not Accept

- Paid-only tools with no free tier
- Affiliate links
- Tools that violate platform terms of service
- Low-quality or spam entries
